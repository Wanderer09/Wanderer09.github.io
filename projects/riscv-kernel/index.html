Implementation & scope

Extended course starter code with ELF image construction, task metadata, and loading; ready/sleep queues and timer interrupts; exec, exit, kill, and waitpid; and barriers, condition variables, and mailboxes. Shell commands expose process operations.

Trap entry saves the interrupted register context. The context-switch routine preserves callee-saved state, while C code manages queues and kernel services. Development used the course toolchain, QEMU, and GDB.

Later multicore and Sv39 branches are experimental, with unfinished locking and memory-management changes. Filesystem and networking are outside the completed scope shown here.
