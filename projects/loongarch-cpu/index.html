LoongArch32 Pipelined Processor Design

I designed and implemented a LoongArch32 pipelined CPU with a 67-instruction subset, exception and interrupt handling, a TLB-based MMU, AXI bus, and instruction/data caches.

The design was brought up on FPGA and verified with representative workloads in a computer architecture course project.

Verilog, computer architecture, FPGA, LoongArch32
